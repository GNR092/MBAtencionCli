# MB Signature Properties - Executive Ledger System

## Direction
A senior-level financial and real estate interface. It should feel like an expensive physical ledger: precise, elegant, and technical.

## Tokens
- **Surface (Night Blue):** `#0d1f30` (used with 80-92% opacity + backdrop blur)
- **Accent (Gold):** `#d8c495`
- **Text Primary:** `rgba(255, 255, 255, 0.95)`
- **Text Secondary/Meta:** `rgba(255, 255, 255, 0.6)`
- **Border:** `rgba(216, 196, 149, 0.15)`

## Patterns
- **Tables:** Semantic alignment. Numbers/Money to the right (Monospace), IDs to the center, Text to the left.
- **Inputs:** Dark "inset" fields. `bg-black/20` with `border-white/10`. Gold border on focus.
- **Buttons:**
    - **Primary:** Gold background, Night Blue text.
    - **Secondary:** Transparent with white/10 background and subtle border.
- **Status:** Subtle "pills" instead of loud colored text.

## Spacing
Base unit: `4px` (Tailwind standard).
